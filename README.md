# El Bidón - Fantasy Fútbol

App web de fantasy fútbol para grupos de amigos. Predice, vota, juega.

## Stack

- **Frontend**: React + responsive design (mobile-first)
- **Backend**: Node.js + Express
- **Database**: PostgreSQL
- **Auth**: Google OAuth

## Estructura

```
el-bidon/
├── backend/        # Node.js + Express API
├── frontend/       # React app
├── db/             # SQL schemas y migrations
└── docs/           # Architecture, decisions
```

## MVP Features

- Autenticación con Google
- Crear/unirse a grupos privados
- Hacer predicciones antes de partidos
- Votar predicciones después de partidos
- Rating de jugadores
- Tabla de posiciones por temporada
- Historial de fechas
